# 阅读排版与组件比例评估

2026-10-03，服务于 [#47](https://github.com/12bitsD/agent4novel/issues/47)。承接 [#35 的字体研究](./frontend-font-options.md) 与作者选定的 BC 黑白灰工作台。两个只读研究分别检查字体节奏和布局比例，交付 Agent 综合后选择方案；研究不是独立完成审核。

## 输入与问题

基线为 main `e04b2be8f8d54a6c0b68a6f96395b9010185246f`。旧桌面截图中的提示、页头、正文采用不同宽度；实际890×750窗口仍保留190px左栏，18字符短章的正文被240px最小高度撑开。2181字符、33个自然段的演示长章用于逐字对照。早先误标宽度的1280px探针已排除；890px基线才作为视觉 RED。

作者本次要求：“字体，空间，各个组件排布和大小你再思考一下能不能优化的更舒服一些？”沿用前次 BC 选择，字号、间距和断点由 Agent 自主收敛。正文原始换行、选段偏移和既有保存保护是保持条件。

## 三个方案

| 方案 | 默认参数和结构 | 收益 | 成本与结论 |
| --- | --- | --- | --- |
| A：保守整理 | 保留20px/1.85/720px阅读列；只统一 UI、辅助字号和按钮 | 改动小，沿用已有字体 | 对短章空白、中屏挤压和阅读轴错位改善不足 |
| B：平衡阅读列与渐进布局 | 桌面20px/1.8/680px，手机18px/1.8；标题28/26px；统一对齐与控件；≤900px单列 | 保留写作工具，减少回行距离和组件空白；不增加模式状态 | 需要检查中屏目录和编辑实际内宽；选用此案并结合 A 的控件统一 |
| C：沉浸阅读与整体重排 | 桌面21px/1.85/672px、手机19px；工具更深折叠或改抽屉 | 阅读视觉更突出 | 手机滚动量和工具切换增加，引入新的导航与草稿恢复关系；本轮不选 |

布局研究另比较比例收敛、阅读主区聚焦和整体重排；采用前两者的组合。最终桌面栏宽200 / 自适应正文 / 256px；901–1150px左栏176px，辅助区置于主区下方；≤900px单列，目录挂载时默认折叠。手机将书名与返回入口并排，长名称仍可换行。

## 字体与空间决定

保留系统宋体正文、系统无衬线 UI 与现有像素品牌，不新增字体资产或 CDN。常规操作14px、常读辅助13px；低频计数仍12px。桌面按钮40px、紧凑导航32px，≤900px两档均44px。正文浅色墨色为#262626，深色为#dedede，辅助区通过底色和边界分层。

680px由正文字号乘34计算，避免父级14px的 `em` 意外缩窄。编辑框用无模糊外描边绘制边界，文字区域不留内边距；因此编辑和预览共用有效内宽和左边线。取消预览最小高度，不清理原始空行，也不把正文拆为段落节点。

## 依据与解释边界

- [W3C 视觉呈现说明](https://www.w3.org/WAI/WCAG22/Understanding/visual-presentation.html)讨论行宽、对齐、间距和可调整性。34字级宽度是项目设计判断，并非该标准指定的唯一默认值。
- [W3C 文本间距说明](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)讨论用户改变间距后仍保留内容和功能；不能据此宣称1.8行距等同全面符合性。
- [W3C 重排说明](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)为窄视口检查提供依据。此次检查320px实际页面；没有以它替代200%缩放及完整无障碍审核。
- [CSS Fonts 4](https://drafts.csswg.org/css-fonts-4/#font-family-prop)定义字体列表与回退；相同字体栈不保证各系统字形和度量一致。

## 实际验证与限制

同一演示长章在1440、1024、890、768、375、320px均保留2181字符与一个纯文本节点，无横向溢出。桌面阅读列680px，手机335/280px；标题和正文共轴。桌面编辑实测内宽680px，字号20px、行高36px。890px短章正文从240px降为36px自然高度。

实测亮暗长章、短章、目录展开/切章/resize、完整高级配置和只读设定。配置草稿折叠后保留，恢复原值后未提交；现有异常、保存、通过、续章和选段保护另由回归测试覆盖。演示文本经过人工编辑，不代表真实模型效果；只观察 macOS 当前浏览器，跨系统字体、200%缩放和用户间距覆写未全面验证。具体证据与交付审核见 [Wiki047](../wiki/047-reading-layout-refinement.md)。
